# Google Form-like Web Form

This project is a clean, minimalistic Google Form-style web form created using only **HTML and CSS**, with no JavaScript. It collects various user details and is styled to be modern, accessible, and responsive.

## 🔧 Features

- Full Name (Text input)
- Contact Number (Phone input)
- Address (Multiline textarea)
- Company Name (Text input)
- Email Address (Email input)
- Department (Dropdown menu: HR, Sales, Development, Marketing, Others)
- Gender (Radio buttons: Male, Female, Prefer not to say)
- Submit button

### Bonus Features

- 🎨 Hover effect on the submit button
- 🖼️ Form has a background color different from the page
- 💡 Minimalistic box-shadow on the form for subtle elevation
